APK BANANE KA TARIQA (sirf phone se, free)
1. github.com par free account banayein, New repository banayein (naam: paisa-app).
2. "uploading an existing file" se is zip ka POORA extract kiya hua content upload karein
   (.github folder samet; hidden folder na dikhe to PC/"Desktop site" use karein).
3. Repository > Actions tab > "Build APK" > agar chala nahi to "Run workflow".
4. 5-8 minute baad run ke andar "Paisa-APK" artifact download karein, zip kholein.
5. app-debug.apk phone par install karein (Unknown sources allow karna hoga).
